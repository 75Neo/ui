# @75neo/styles

The Panda CSS layer shared by every 75NeoUI package.

- `src/preset.ts` — tokens, semantic tokens and recipes, exported as a Panda preset.
- `styled-system/` — generated by `pnpm codegen`; git-ignored, re-created on install.

Component packages import the **runtime** from here (`@75neo/styles/css`,
`@75neo/styles/recipes`) and never generate their own. Apps import the **preset** and run
their own `panda` extraction, which is what actually emits CSS:

```ts
// panda.config.ts in an app
import { defineConfig } from "@pandacss/dev";
import { preset } from "@75neo/styles";

export default defineConfig({
  presets: ["@pandacss/preset-base", preset],
  importMap: "@75neo/styles",
  include: ["./src/**/*.{ts,tsx}", "../../packages/react/src/**/*.{ts,tsx}"],
  outdir: "styled-system",
});
```

The `importMap` is what makes Panda recognise `@75neo/styles/css` imports as its own, and
the library sources in `include` are what make the component recipes land in the output.
